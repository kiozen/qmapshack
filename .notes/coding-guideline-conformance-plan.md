# Coding guideline conformance

Bring the tree in line with `README_CODING.md` (in the repository root, on `Maproom/qmapshack` `dev`).
Wants its own branch. Numbers below are measured over the 859 `.cpp`/`.h` files under `src/`.

## Scope

- `src/` only. `3rdparty/` (306 files, Garmin FIT SDK) is out — the same boundary as `qms_options`,
  which first-party targets link and bundled 3rdparty must not.
- **Autogenerated files are ignored**: the seven qdbusxml2cpp files in `src/qmapshack/device/dbus/`
  (`org.gtk.vfs.*`, `org.kde.kmtp.*`) and `contributors.h` from `collect_copyright.py`. No
  `.clang-format-ignore` exists yet, so this is convention, not enforcement.

## Already clean — do not re-audit

- `qAsConst`, `qMove`, `qExchange`, `Q_FOREACH`: **zero**. The tree is already on `std::as_const`
  (193 uses).
- Class naming: zero first-party violations. The 13 non-`C`/`I` classes are all in the autogenerated
  D-Bus and MTP files.
- Signal naming: the six signals not called `sig*` are `Q_PROPERTY` `NOTIFY` signals
  (`valueChanged`, `dateTimeChanged`, `animatedColorChanged`, `opacityChanged`, …). They are correct
  as they stand — the guideline carves them out.
- Include guards: 433 files, no `#pragma once`.
- 3561 Qt-typed tokens are already in place.

## Traps

- **`NULL` is 86 grep hits but only 12 real pointers.** The other 71 are SQL text inside string
  literals (`"… IS NULL"`) in `IDBSqlite.cpp`, `IDBMysql.cpp` and `CQlgtDb.cpp`. A blind
  `sed s/NULL/nullptr/` corrupts the queries and fails at runtime against a database, not at build
  time. Hand-edit the 12; several are Win32 calls in `CAppSetupWin.cpp`.
- **`m_`: 186 of the 244 occurrences are in `CDateTimeEditor` (134) and `CLedIndicator` (52).** A
  rename can collide with an existing local or parameter and silently bind to the wrong variable.
  Per file, reviewed, never scripted.
- **`#define` → `constexpr`: none of the 58 are used in `#if`/`#ifdef`** — checked, so the usual
  hazard is absent. The residual is a now-typed constant changing an overload or a promotion
  (`NOINT`, `NOFLOAT`, `MIN_WIDTH_INFO_BOX`).

## Why a sweep is compile-verified here

The three mechanisms that normally turn a Qt rename sweep into silent runtime breakage are all
absent:

- **No name-based auto-connection.** Zero slots named `on_<object>_<signal>`, so the
  `connectSlotsByName()` inside every `setupUi()` connects nothing by name and a slot rename cannot
  drop a connection.
- **Connections are compile-checked.** 1076 pointer-to-member `connect()` against 8 surviving macro
  occurrences.
- **885 `override`s.** A changed virtual parameter type is a build error, not a new overload that
  never gets called.

Nothing here touches `tr()` text, so the `.ts` catalogs stay untouched.

## Batches

1. **Mechanical, compile-verified, ~450 lines.** clang-format the 41 hand-written files, 11
   `virtual`+`override`, 8 macro connects, 1 `foreach`, 13 header `using`, 12 copyright headers, 12
   real `NULL`s.
2. **Per file, reviewed.** 58 macro constants, 22 structs, 22 enum items, the 12 `m_` files.
3. **Never sweep.** `int` → `qint32` and `explicit`. The guideline already exempts API boundaries,
   and 1966 sites of churn would bury any real change in review. Fix them in files touched anyway.

## `CDateTimeEditor` — restore the MIT notice

`src/qmapshack/widgets/CDateTimeEditor.{h,cpp}` is imported from
<https://github.com/flopp/QtDateTimeEditor>, copied in `1e717339e` (2022-05-21,
`[QMS-518] Add dataetime editor by Florian Pigorsch`).

Upstream is **MIT**: *"The MIT License (MIT) — Copyright (c) 2015 Florian Pigorsch
<mail@florian-pigorsch.de>"*. The imported file kept his copyright line but replaced the MIT text
with the project's GPL-3 header. Relicensing MIT into a GPL-3 project is fine, the licences are
compatible, but MIT requires its permission notice to travel with copies.

**Restore the MIT notice in the file, alongside the GPL-3 header.** Additive, no code change.

Its `m_` prefix and `dateTimeChanged` signal are upstream conventions, inherited untouched — the
import matched the formatting but not the naming. The include guard is still `QTDATETIMEEDITOR_H`
from the original class name.
